# @incident/evals

M1 工作包。评估数据集、promptfoo 配置、故障注入与快照录制脚本。

**范围**

- 故障注入：通过 OTel Demo 的 flagd 注入故障，等告警触发，录制当时的遥测快照到 `REPLAY_DIR`，标注标准根因
- 检索集（约 100 条）、故障集（≥ 40 条）、对抗集（约 20 条）
- LLM-as-judge 的评分标准与校准（与人工打分一致率 ≥ 90%）
- 预算守卫：运行前估算花费，当月用量超过 80% 时只允许冒烟评估

**G1 验收**：录制脚本能产出 3 条可回放的故障样本；promptfoo 能对 stub agent 跑通。
