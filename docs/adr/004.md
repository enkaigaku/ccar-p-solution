# ADR 004：工具通过 MCP 暴露，读写拆成两个 server，用官方 MCP SDK 实现

- 状态：已接受
- 日期：2026-11-12

## 背景

同一组排障工具既要给 agent 用，也要给 Claude Code / Claude Desktop 人工排障复用；写操作必须在架构上与 agent 隔离。

## 决定

`mcp-observability`（只读，挂到 agent）与 `mcp-ops`（写，只给审批执行器）两个 server，均用 `@modelcontextprotocol/sdk` 实现；工具 Schema 定义在 contracts。

## 备选方案

进程内函数调用（无法多客户端复用）；单个 MCP server 按工具粒度授权（隔离边界弱）。

## 后果

最小权限通过「移除能力」实现，而不是确认弹窗或日志。
