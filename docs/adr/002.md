# ADR 002：后端用 Effect 4，前端用 TanStack Start 1

- 状态：已接受
- 日期：2026-11-12

## 背景

需要类型化错误、依赖注入、重试与超时组合，以及前后端共享的 HTTP 契约。

## 决定

后端用 `effect` 4.x 的 `effect/http-api`；前端用 TanStack Start 1.x，并从 `IncidentApi` 派生类型安全客户端。

## 备选方案

Fastify/Hono + 手写类型；Next.js。

## 后果

Effect 4 刚稳定，社区示例多为 v3，需在 AGENTS.md 中约束只用 v4 API，并指向包内自带文档。
