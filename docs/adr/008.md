# ADR 008：观测后端用 Grafana 全家桶，暂不接 Langfuse

- 状态：已接受
- 日期：2026-11-12

## 背景

需要同时观测被运维系统和本系统；OTel Demo 已自带 Grafana / Prometheus。

## 决定

Grafana + Tempo + Loki + Prometheus；Langfuse 留到 M4 作为可选对比实验。

## 备选方案

Langfuse（LLM 专用视图、prompt 管理、数据集），自部署需 ClickHouse 等组件。

## 后果

LLM 调用的阅读体验不如专用工具，由 SDK 的 GenAI span 和审计表弥补。
