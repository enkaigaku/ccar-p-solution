# ADR 003：Claude 只通过官方 `@anthropic-ai/sdk` 接入

- 状态：已接受
- 日期：2026-11-12

## 背景

本项目是围绕 Claude 生态的学习项目，需要直接接触原生 API 形态：缓存断点、thinking 块、stop_reason、fallbacks、新 beta 功能。

## 决定

只用官方 SDK，包成一层薄的 `ClaudeClient` Effect Service：Promise 转 Effect，类型化异常映射为可重试 / 不可重试错误。

## 备选方案

`@effect/ai-anthropic` 为主、官方 SDK 备用（被否决：多一层抽象，学习价值低，新功能有滞后）。

## 后果

SDK 自带的 OpenTelemetry 支持（beta）直接提供 GenAI span。
